# 工作流与行为准则
- **使用中文回答**：无论我用什么语言提问，你都必须使用中文回答我。
- **先读后写**：在修改任何代码之前，必须先阅读相关函数及其上下文，不要盲目猜测。
- **小步修改**：每次只修改一个明确的问题（例如只修复一个编译错误），不要一次性重写整个文件。
- **不要自作主张**：如果你（AI）觉得自己无法100%确定如何修复，请直接向我提问，而不是盲目尝试。
- **解释你的思路**：每次修改代码后，用简短的中文告诉我：你改了哪里？为什么这么改？这能解决什么问题？
- **GitHub提交一步到位**：当我要求提交代码时，请直接合并执行，不要反复请示。但**严禁使用 `git add .` 或 `git commit -a` 盲目提交所有文件**。请只 `git add` 我明确指出的相关代码文件（如 `*.cpp`, `*.h`），或者先用 `git status` 确认后再提交。如果你没有弄明白要上传哪个文件或者上传文件时出现矛盾，把问题告诉我，不要擅自行动。
